# Dúchfómhair pictures

Pictures for the live Dúchfómhair year on tuathan.com/art-projects.
They're served from here (GitHub Pages) so adding one never uses Netlify credits.

**Each day:** open `inbox` → Add file → Upload files → pick the photo → Commit.
A minute or two later it's compressed, numbered, and on the site with the ? after it.

- Name a photo just `5.jpg` to replace piece 5.
